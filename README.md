## Проект 3. BI-дашборд для анализа ключевых финансовых показателей брендов

**Цель:**
Построить дашборд для анализа основных финансовых показателей брендов компании, которая занимается продажей товаров в сфере красоты.

Цели дашборда:
- анализ эффективности продаж
- разработка стратегии компании
- управление ассортиментом брендов и продуктов

**Стек:** Excel, Yandex DataLens.

## Описание и задачи проекта
Этот дашборд позволит отслеживать общие метрики и поможет решать задачи:
- анализ эффективности текущего ассортимента,
- привлечение новых брендов и поддержка существующих,
- оптимизация ассортимента путем отказа от непопулярных продуктов.

## Реализация проекта
- Работа выполнена на Yandex DataLens. 
- Определила цели, задачи и аудиторию дашборда - руководство и бренд-менеджеры.
- Разработала Dashboard Canvas и структуру аналитического решения.
- Подготовила данные из Excel для визуализации.
- Создала интерактивный дашборд в Yandex DataLens
- Реализовала мониторинг выручки за месяц и ее динамики относительно прошлого месяца,
объема продаж, процента выкупа и динамики ключевых показателей.
- Настроила фильтры и подготовила документацию к дашборду.

[Готовый дашборд на Yandex DataLens](https://datalens.ru/3teow6ep2q5km-brendy-klyuchevye-finansovye-metriki)

## Результат
Дашборд позволяет руководству и бренд-менеджерам анализировать эффективность текущего ассортимента и использовать данные при принятии решений о оддержке
существующих брендов, привлечении новых и оптимизации ассортимента.
